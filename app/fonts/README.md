# Cinzel

`cinzel-latin.woff2` : sous-ensemble latin (accents francais compris) de Cinzel
(Natanael Gama), police variable 400-900, sous **SIL Open Font License 1.1**
(https://openfontlicense.org). Source : Google Fonts.

Auto-hebergee pour rester disponible hors-ligne. `app.css` la charge via
`@font-face` et l'applique aux titres (`--font-title`), avec Nunito en repli.
